## 🎯 一、产品定位与核心价值主张

### 1.1 核心价值主张（v2.0 升级版）

**"逃离城市喧嚣，经营属于你的理想农场 —— 不只是种田，而是经营一种人生。"**

v2.0 在保留治愈经营核心的基础上，强调 **"无限可玩性"** 与 **"选择性挑战"**。游戏不仅提供治愈的种田体验，更为深度玩家准备了"传说级挑战"、"自动化工业"与"隐藏结局"，确保不同粘性的玩家都能找到属于自己的目标。

### 1.2 目标用户粘性与内容支撑（v2.0 目标）

| 用户类型 | 特征描述 | v2.0 目标游戏时长 | 核心留存锚点（新增） |
|----------|----------|-------------------|---------------------|
| 🐢 休闲玩家 | 每日 < 1小时 | 150-250+ 小时 | 冬季室内装饰、宠物养成、NPC剧情解锁 |
| 🐇 中度玩家 | 每日 1-2小时 | 250-400+ 小时 | 社区中心收集、温室自动化、节日逐年升级 |
| 🐺 硬核玩家 | 每日 > 2小时 | 500-1000+ 小时 | 100层矿洞+Boss、传说鱼/作物、速通成就、多结局 |

### 1.3 核心体验关键词（v2.0 扩展）

- 🌱 **成长感**：作物生长、农场扩张、技能提升
- 💰 **成就感**：金币累积、收藏完成、传说解锁
- 💕 **亲切感**：NPC社交、宠物陪伴、节日温情
- 🌅 **探索欲**：100层矿洞、隐藏区域、传说秘密
- 🍵 **放松感**：慢节奏玩法、风水布局、装饰建造
- ⚡ **挑战感**：Boss战、速通、极限收集（新增）

## 🎮 二、核心玩法循环（v2.0 增强）

### 2.1 每日游戏循环

```
🌅 新的一天开始
    │
    ├── ☀️ 早晨：起床 → 查看邮件/天气预报/宠物状态
    │
    ├── 🌱 上午：农场劳作（可选自动洒水器协助）
    │   ├── 给作物浇水（或检查洒水器）
    │   ├── 播种/收获/加工（腌菜桶/酿酒桶/果酱机）
    │   ├── 照料动物（抚摸/挤奶/剪毛）→ 新增【宠物伙伴】协助放牧
    │
    ├── 🍽️ 中午：社交/探索/挑战
    │   ├── 与NPC对话（好感度10级系统）
    │   ├── 赠送礼物 / 触发剧情事件链
    │   ├── 探索矿洞（100层）/ 钓鱼（传说鱼）
    │   ├── 前往新区域：【海滩码头】/【秘密森林】/【山间祭坛】
    │
    ├── 🌙 晚上：总结/风水布局/加工
    │   ├── 出售产品 / 布置农场"风水"摆件（新增增益系统）
    │   ├── 购买种子/升级工具/献祭收集包
    │   ├── 合成高级物品 / 规划明日布局
    │
    └── 💤 结束一天：睡觉 → 自动存档 → 进入下一天
```

| 风水组合 | 所需物品 | 增益效果 | 解锁方式 | 核心定位 |
|----------|----------|----------|----------|----------|
| **水源之阵** | 4个喷泉 + 1个池塘 | 周围 5×5 格作物自动浇水 | 第一年夏 | 新手必选 |
| **丰收之阵** | 8个灯笼 + 1个稻草人 | 收获时额外掉落 10% 作物 | 第一年秋 | 产量核心 |
| **幸运之阵** | 4个水晶 + 1个祭坛 | 矿洞矿石掉落率 +15% | 第二年 | 探索辅助 |

> ⭐ = v2.0 新增阵法

#### 4.1.2 风水相克机制（v2.0 新增）

为防止"最优解"固定化，增加阵法相克规则，要求玩家根据季节和目标动态调整：

```
风水相克规则表:
┌─────────────────────┬─────────────────────┬──────────────────────────┐
│ 主动阵法              │ 被克阵法              │ 冲突效果                  │
├─────────────────────┼─────────────────────┼──────────────────────────┤
│ 水源之阵              │ 丰收之阵              │ 同时激活时，作物生长速度   │
│ (水克火)              │ (火属性)              │ 降低10%（水多涝根）        │
├─────────────────────┼─────────────────────┼──────────────────────────┤
│ 动物守护阵            │ 水源之阵              │ 同时激活时，动物产出       │
│ (土属性)              │ (水属性)              │ 降低5%（土克水）          │
├─────────────────────┼─────────────────────┼──────────────────────────┤
│ 灵气汇聚阵            │ 幸运之阵              │ 同时激活时，矿洞掉落率     │
│ (木属性)              │ (金属性)              │ 额外降低5%（金克木）      │
├─────────────────────┼─────────────────────┼──────────────────────────┤
│ 蜂蝶环绕阵            │ 动物守护阵            │ 同时激活时，蜜蜂会干扰     │
│ (虫属性)              │ (土属性)              │ 动物休息，心情-5          │
├─────────────────────┼─────────────────────┼──────────────────────────┤
│ 混元太极阵            │ 无（终极阵法）          │ 与所有阵法兼容，提供       │
│ (调和属性)            │                       │ 20%增益加成                │
└─────────────────────┴─────────────────────┴──────────────────────────┘
```

**相克策略要点**:
1. **同区域冲突**：两个相克阵法在同一农场区域（半径 7 格内）时触发冲突
2. **跨区域共存**：阵法位于农场不同区域时可共存（如：水源阵在东田，丰收阵在西田）
3. **季节调节**：某些阵法组合在特定季节不冲突（如：水源+丰收在冬季可共存）
4. **玩家策略**：鼓励玩家根据当季作物和目标，动态调整阵法布局
5. **混元太极阵**：第三年解锁，可作为"百搭"阵法，与任何阵法组合无冲突

#### 4.1.3 风水增益叠加规则

```
叠加机制:
├── 同类阵法: 同类型增益取最高值（不叠加）
├── 异类阵法: 不同类型增益可同时生效（如：浇水+产量）
├── 混元加成: 太极阵为其他阵法提供额外20%增益
├── 冲突惩罚: 相克阵法同时激活时，双方增益降低30-50%
└── 区域效应: 阵法仅影响其覆盖区域（5×5 ~ 7×7 格）
```

### 5.3 NPC 互动新机制（v2.0 新增）

#### 5.3.1 NPC 朋友圈动态系统（v2.0 扩展）

NPC 之间的关系会随玩家行动动态变化，形成"社交网络"：

```
NPC 关系网示例:
├── 店主 ←→ 铁匠: 商业伙伴关系
│   ├── 玩家与店主好感高 → 铁匠吃醋，触发"商业间谍"任务
│   ├── 玩家与铁匠好感高 → 店主警惕，商店折扣减少
│   └── 两者都高 → 联合提供"合作优惠"
├── 医生 ←→ 诗人: 挚友关系
│   ├── 玩家送医生礼物 → 诗人会赠送感谢礼物
│   └── 玩家完成诗人任务 → 医生解锁新治疗方案
├── 渔夫 ←→ 镇长: 利益相关
│   ├── 玩家发现传说鱼 → 镇长颁发奖项
│   └── 渔民节日互动 → 镇长改变节日安排
└── 跨阵营关系: 
    └── 镇长 ←→ 铁匠: 镇长想修建新建筑 → 铁匠提供折扣
```

**动态事件触发条件**:
| 事件类型 | 触发条件 | 效果 |
|----------|----------|------|
| 吃醋事件 | 玩家与 A 好感度 > B，同时见 B | B 好感度 -2，触发特殊对话 |
| 友情联动 | A 和 B 都达到 5 心 | 解锁联合任务或交换礼物 |
| 利益冲突 | 玩家接受 A 的任务同时接受 B 的对立任务 | 需要做出选择，影响一方好感度 |
| 社交传播 | 玩家向 A 透露 B 的秘密 | A 会告知 B，触发连锁事件 |
| 团体活动 | 3 个以上 NPC 好感度 > 3 心 | 触发城镇聚会事件 |

#### 5.3.2 其他互动机制

- **周年纪念日**：每年特定日期，高好感度 NPC 会赠送特别礼物（第二年纪念品比第一年更稀有）
- **主动帮忙**：8心以上 NPC 会在早晨主动来农场帮忙（除草/浇水/喂食）
- **隐藏剧情**：10心解锁 NPC 的背景故事支线
- **好感度继承**：玩家与 NPC 关系在第二年延续，NPC 会记得第一年的互动

#### 9.3.2 燃料系统设计

```
燃料获取途径:
├── 煤炭: 矿洞 1-40 层掉落，每日上限 10 块
├── 电池: 手工合成（铜×2 + 铁×1），或商店购买 500G/组
├── 高级电池: 铱锭×1 + 电池×3 合成，效率 +300%
└── 生物燃料: 秋季获得，效率仅 50% 但可通过种植再生

燃料消耗机制:
├── 每日结算: 设备每日自动消耗燃料，燃料不足时设备停机
├── 提前补充: 玩家可提前为设备补充 3-7 天燃料
├── 紧急停机: 燃料耗尽时设备自动停用，弹出通知
├── 燃料加成: 高级电池可提供 3 倍使用时长
└── 自动化成本: 每日维持 4 台自动化设备约需 8,000-15,000G/月（燃料成本）
```

#### 9.3.3 自动化经济平衡

```
投入产出分析 (示例):
├── 铱金洒水器:
│   ├── 投入: 水壶升级 (约 25,000G) + 煤炭成本 (30G/天)
│   ├── 产出: 节省浇水时间，多种植 20% 作物
│   └── 回收周期: 约 30 天
├── 自动收获机:
│   ├── 投入: 设备费 50,000G + 电池成本 (250G/天)
│   ├── 产出: 每日节省 1 小时，避免作物过熟损失
│   └── 回收周期: 约 45 天
└── 智能仓库:
    ├── 投入: 100,000G 建造费 + 电力成本
    ├── 产出: 节省整理时间，实现物品分类管理
    └── 回收周期: 约 60 天
```

**设计理念**: 自动化是"锦上添花"而非"必需品"，玩家需权衡燃料成本与时间效率。休闲玩家可完全不使用自动化，手动操作依然高效。
